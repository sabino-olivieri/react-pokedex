# Pokémon Pokedex React

Il **Pokédex** è il primo progetto che ho sviluppato utilizzando **React**, una potente libreria JavaScript per la creazione di interfacce utente. In questo progetto, ho voluto mettere in pratica ciò che ho imparato, integrando diverse funzionalità per offrire un'esperienza interattiva e completa.

## Funzionalità Principali

- **Ricerca Pokémon**: Permette di cercare qualsiasi Pokémon inserendo il nome e ottenendo una lista di suggerimenti in tempo reale.
- **Visualizzazione Dettagliata**: Mostra informazioni complete sul Pokémon selezionato, come tipi, statistiche principali, debolezze contro altri tipi, e altre informazioni utili.
- **Catena Evolutiva**: Esplora la catena evolutiva di un Pokémon, indicando quando e come il Pokémon si evolve nelle sue forme successive.
- **Cattura Pokémon**: Simula la cattura di un Pokémon. I Pokémon catturati vengono salvati in local storage e una notifica toast conferma l'avvenuta cattura.

## Tecnologie Utilizzate

- **React**: Libreria frontend per la costruzione dell'interfaccia utente.
- **Redux**: Utilizzato per gestire lo **stato globale** dell'applicazione, facilitando la gestione centralizzata dei dati tra i vari componenti.
- **Vite**: Build tool veloce per lo sviluppo frontend.
- **PokeAPI**: API pubblica utilizzata per ottenere i dati dei Pokémon.
